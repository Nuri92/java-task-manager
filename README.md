# Java Task Manager

A console-based task manager application built with pure Java.

## Features

- Create tasks
- Show all tasks
- Search tasks
- Delete tasks
- Mark tasks as completed
- Mark tasks as in progress
- File persistence with tasks.txt
- Custom exceptions
- Repository pattern
- Service layer architecture

## Technologies

- Java
- OOP
- Interfaces
- File I/O
- Git
- GitHub

## Project Structure

Main
↓
TaskService
↓
TaskRepository (Interface)
↓
TaskMemoryRepository
↓
TaskFileRepository
